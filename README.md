## ✨ Key Features

- 🌌 **Constellation Particle Network**: Dynamic HTML5 Canvas background simulating neural/blockchain node links with real-time mouse repulsion and proximity attraction.
- 🤖 **RecoverX AI Agent Simulator**: Interactive in-browser visualizer of the 5-phase autonomous loop:
  $$\text{DETECT} \longrightarrow \text{REASON (Google Gemini API)} \longrightarrow \text{DECIDE} \longrightarrow \text{ACT} \longrightarrow \text{VERIFY}$$
  Includes 4 failure scenarios (UPI gateway timeout, card decline, subscription drop, and dropped webhook).
- 💻 **Recruiter Hacker CLI Terminal**: Interactive terminal modal (press `CLI` button in navbar or hit **\`** backtick) with custom commands: `about`, `skills`, `projects`, `experience`, `recoverx`, `contact`, and `clear`.
- 🗂️ **Filterable Skills Engine**: Real-time filtering across *Languages*, *Web & MERN*, *AI/ML & LLMs*, *Tools*, and *Practices*.
- 📋 **1-Click Quick Connect**: Instant copy-to-clipboard for Email and Phone with animated toast feedback.
- 📱 **Fully Responsive Glassmorphism**: Tailored for mobile, tablet, and ultra-wide screens with smooth CSS transitions and 60 FPS performance.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/yashcodemaker/yaswanth-portfolio.git
cd yaswanth-portfolio
```

### 2. Run locally

**Option A: Direct Open**
> Double-click `index.html` to open it in Chrome, Brave, Edge, or Firefox.

**Option B: Python HTTP Server**
```bash
python -m http.server 8080
# Open http://localhost:8080 in your browser
```

**Option C: Node.js / npx serve**
```bash
npx serve .
```

## 🌐 Deployment to GitHub Pages

Deploying takes under 2 minutes:

1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "feat: launch animated developer portfolio"
   git branch -M main
   git remote add origin https://github.com/yashcodemaker/<your-repo-name>.git
   git push -u origin main
   ```
2. On GitHub, navigate to **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Your portfolio will be live at:
   `https://yashcodemaker.github.io/<your-repo-name>/`
